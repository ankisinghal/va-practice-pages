Two copies of which moment?

Test ID: Topic: Editorial difficulty: (a guess before reading, not a measured level)
Words: Reading time: about 2 minutes
Source: original fictional passage written for practice, so full text is included.

In an imagined design studio, Asha keeps a folder of drawings on two computers. Her invented copying program makes the second folder match the first each evening. When she adds a drawing, it appears on both machines. When she deletes one, it disappears from both. Seeing both folders, her colleague declares that the studio has a backup. Asha asks what kind of loss he expects it to protect against.

If the first computer fails while the second remains intact, the extra copy may be valuable. But suppose Asha accidentally deletes the wrong drawing before the update. The program obediently removes the second copy too. It has followed its design. The failure lies in expecting a system that preserves agreement between folders to preserve a previous state when that agreement changes.

Asha proposes keeping dated versions in a separate archive. That would make yesterday's drawing available after today's mistaken deletion, provided yesterday's version was saved and the archive remained accessible. Her colleague objects that several versions of the same file will create confusion. He is right about a cost, but the confusion is not an accidental defect that perfect matching would remove. Distinguishing versions is part of preserving a choice between them.

The archive introduces its own questions. How long are earlier versions kept? Can an ordinary editing mistake erase the archive as well? Can the studio actually open an old drawing with its current software? A large number of saved files answers none of these questions by itself. Asha therefore separates the working folders, where agreement is useful, from the archive, where some differences must survive. She does not call one arrangement a substitute for the other.

At the meeting, she brings a deliberately discarded practice drawing back from the archive. The recovery checks one saved version under the conditions of that exercise; it is not a guarantee against every possible failure. Its value is more specific: the studio can see which earlier state was available and how it was retrieved. The extra folder is no longer a reassuring picture. Each safeguard must answer a named kind of loss.
